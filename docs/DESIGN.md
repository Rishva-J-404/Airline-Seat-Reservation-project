# AeroPrecision Design System (FlySmart Airlines)

## Design Vision
A high-trust, premium commercial aviation design system tailored for airline flight reservation, seat selection, and operational telemetry. Clean, crisp, accessible, and structured with clear information hierarchy.

## Color Palette
- Primary Brand: Deep Aero Navy (#0A192F, #0F2444, #1B365D)
- Action Accent: Flight Azure (#0066FF, #2563EB, #3B82F6)
- Neutral Canvas: Crisp Aviation White (#FFFFFF), Cloud Slate (#F8FAFC, #F1F5F9, #E2E8F0)
- Typography Ink: Midnight Slate (#0F172A), Muted Slate (#64748B)

## DSA Functional Telemetry Colors
- Queue ADT (CO1): Royal Violet (#6366F1)
- Passenger Manifest (CO2): Precision Cyan (#06B6D4)
- Fare Selection Sorter (CO3): Amber Gold (#F59E0B)
- BST PNR Index (CO3): Radiant Orange (#F97316)
- AI Seat Matcher: Emerald Green (#10B981)

## Aircraft Seat Cabin States
- Available: White / Slate-100 with Slate-300 border
- Selected: Flight Azure (#0066FF) with white armchair indicator
- Occupied: Slate-200 with light crosshatch / muted fill
- Premium / Extra Legroom: Soft Emerald / Azure outline with badge
- AI Best Match: Glowing Emerald (#10B981) highlight

## Typography & Hierarchy
- Headings: Outfit / Space Grotesk (700 Bold, 800 Extrabold)
- Body: Inter / System Sans-serif (400 Regular, 500 Medium)
- Monospace Data: JetBrains Mono (PNR, Seat Number, Flight Code, Timestamps)

## Component Tokens
- Radius: Cards (12px rounded-xl), Buttons (8px rounded-lg), Inputs (8px rounded-lg), Badges (9999px rounded-full)
- Elevation: shadow-xs, shadow-sm (subtle crisp elevation, no heavy drop shadows)
- Transitions: 150ms ease-in-out
